Una medida que nada puede romper es decoración

Cuando un agente escribe el producto y su verificador en la misma pasada, puede hacerlos coincidir sin detectar el defecto. El corpus guarda casos rojos y verdes; la mutación debilita la regla a propósito y comprueba si los casos lo notan.

El criterio deja de ser consejo: una medida debe poder negarse y mostrar testigos. Por qué mutar las medidas.

el lenguaje · álgebra 0.8 · sintaxis 0.7

La regla nombra el defecto

Esta medida es el archivo real colocacion.dentro_del_tablero.oracle:

colocacion.dentro_del_tablero.oracle
medida colocacion.dentro_del_tablero:
    de celda_ocupada c
    donde c.fila < 0 o c.fila > 9 o c.columna < 0 o c.columna > 9
    resumen contar(1)
    umbral <= 0 segun contrato porque "el tablero es de 10x10 (coordenadas 0 a 9); cualquier casilla fuera de ese rango corrompe el estado del juego"
    requiere celda_ocupada
    ambito universal
    alcance "valida que las celdas reportadas estén en el rango 0..9. NO ve si los buques tienen la longitud declarada ni si se solapan entre sí"
  • de / dondeEntran hechos y quedan las filas que ofenden.
  • umbralsegun declara de dónde sale el número.
  • requiereLa ausencia de la relación no se disfraza de verde.
  • alcanceLa medida declara su punto ciego.

La anti-junta dice «ninguna»

Desde 0.26, sin … donde … deja pasar una tarea cerrada sólo si no existe un commit de cierre que corresponda a ella. Ese conteo entra al álgebra, al diferencial y a la mutación.

recorte: seguimiento.toda_tarea_cerrada_tiene_su_commit_de_cierre.oracle, líneas 1–5

medida seguimiento.toda_tarea_cerrada_tiene_su_commit_de_cierre:
    de tarea_seguimiento t
    donde t.estado_declarado == "CERRADA"
    sin commit_seguimiento c donde c.tarea_nombrada == t.id y c.es_cierre == true
    resumen contar(1)

El archivo completo también declara umbral, ambito del_origen y alcance.

Escribí la aritmética como la pensás

La sintaxis 0.7 acepta a + 1, a - 1 y a * 2, con precedencia y paréntesis habituales. Incluso t1.turno-1 se lee como resta, sin exigir espacios. Se traducen a las escalares existentes mas, menos y por; la forma canónica y el álgebra 0.8 no cambian. Así un LLM puede escribir t2.turno == t1.turno + 1 sin reformular la expresión.

Un verde con alcance

oracle test contrasta medidas con casos guardados. La salida declara ALCANCE y PRODUCTO: sin nueva medición: no certifica el estado actual de la aplicación. En un proyecto nuevo sin medidas propias, casos ni fixtures, dice VEREDICTO: SIN MEDICIÓN y sale con código 0.

recorte de corrida real · comando y salida completa

$ python3 tools/cli.py test --proyecto ejemplo/primer-valor
ALCANCE: verificación de medidas contra casos guardados del corpus.
PRODUCTO: sin nueva medición; la aceptación no reejecuta los comandos de origen ni el producto. El resultado no certifica su estado actual.
VEREDICTO: VERDE (todas las verificaciones aplicables en regla)

La corrida del proyecto vacío muestra el otro veredicto.

juzgar el producto · 0.27

La sombra tiene cota

El producto exporta relaciones JSON; oracle juzgar evalúa esas filas. Una medida en sombra puede perdonar sólo hasta su cota. Si la supera, vuelve el rojo. Cuando otra medida necesita una relación que no vino, aparece bajo NO SE APLICARON.

recorte de corrida real · salida completa

✗ colocacion.dentro_del_tablero  1 (<= 0)   [EN SOMBRA] (SUPERA SU COTA 0: la sombra no la perdona; desde 2026-09-24; porque: piloto de cota)
      → c={'barco': 'destructor', 'fila': 10, 'columna': 5}

recorte de corrida real · salida completa

NO SE APLICARON (1) — su relación no vino en la evidencia:
  · prosa.alcance_sin_afirmacion_adversa: falta afirmacion_prosa

Primer valor: una regla del juego

En el ejemplo de Batalla Naval, colocador.py emite celda_ocupada. Una medida exige coordenadas de 0 a 9; seis casos fijan ambas polaridades y matan 20/20 mutantes de la medida. Tras verificar el catálogo, una corrida defectuosa produce un testigo con fila: 10; la corrida corregida da verde y enumera lo que no miró.

Jev · sensor de prosa

El modelo produce hechos; la medida juzga

El sensor opcional convierte respuestas probabilísticas en filas afirmacion_prosa. Oracle juzga esas filas sin llamar al modelo ni a la red. Un verde no certifica la verdad de la prosa.

Señal

En la primera prueba: 10/10 controles de prosa vacía, 15/15 en cada pregunta de alcance frente a un juez ciego; la pregunta original sobre porque cayó a 1/15. Las seis llamadas costaron US$ 0,000877044.

Corrección

Con pregunta y tubería revisadas, porque coincidió 15/15 en reales y 10/10 controles. Costó US$ 0,001443666. Los sí quedaron entre 0,50 y 0,68; dos tocaron exactamente 0,50. El piloto de síntoma en LyraGASP bajó a 9/15, con Jev indulgente en los nueve desacuerdos. Los pilotos de Jam y LyraGASP no sostienen una precisión universal.

Revisión humana

Probabilidades de 0,4 a 0,6 van a revision-humana.json y el sensor termina con código 2. Desde PyPI, oracle plantilla sensor-prosa <destino> copia el proyecto opcional; el usuario ejecuta el sensor por separado.

El tracker es el relevo

Cada tarea vive en Git, en tareas/<id>/TAREA.md. Su única sección final ## Próximo paso dice qué hacer al retomar. oracle tarea ver web-028 resuelve el sufijo; no hace falta reconstruir la fecha. CIERRA CON puede exigir medidas verdes para cerrar.

El servidor fija el proyecto al arrancar y no crea ni modifica archivos. Evita que una consulta de evidencia o una prueba de falsación parezca una aprobación para guardar una medida. El contrato MCP se genera desde tools/mcp.py mediante tools/mcp_contrato.py.

La sonda de clientes observó: Claude Code ve descripciones y structuredContent; Codex ve también el texto; agy ve descripciones y texto, pero no structuredContent. Ninguno expuso outputSchema al modelo. Por eso el servidor conserva las dos formas de respuesta.

Empezar

Instalá Oracle con uv tool install oracle-metalenguaje o pip en un entorno virtual. El LSP comparte diagnósticos entre Emacs y VS Code. Para conectar una aplicación, empezá por una regla y hechos observables: primer valor.

uv tool install oracle-metalenguaje
oracle init mi-proyecto
oracle nueva dominio.regla
oracle test

Secuencia para usar, sin salida simulada. De cero a un rojo explica cada paso.

Experimental, con límites explícitos

L2 conserva mecanismos en Python. El estado de un producto requiere hechos nuevos; un corpus verde no reemplaza esa observación. Las doce decisiones de diseño documentan lo aceptado y lo descartado.
